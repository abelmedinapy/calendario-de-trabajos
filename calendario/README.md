# Calendario de trabajos

El tablero del día de Abel: en qué proyectos va a trabajar, qué toma de cada
uno y qué hay que hacerle. Una sola pantalla, modo oscuro, pensada para sacarle
una captura y mandarla.

Diseño: `../docs/superpowers/specs/2026-10-18-calendario-diseno.md`
Plan: `../docs/superpowers/plans/2026-10-18-calendario-pwa.md`

## Correr los tests

    npm test

Sin dependencias: usa el corredor de tests que trae Node.

## El día empieza a las 5

El corte no es a medianoche sino a las 05:00 de `America/Asuncion`. A las 2 de
la mañana el tablero sigue siendo el de ayer. Vive en `src/dia.js`.
